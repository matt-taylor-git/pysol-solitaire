# Klondike Solitaire Rules

## Objective
The goal is to move all cards to the foundation piles, building them up from Ace to King in suit.

## Setup
- Deal 7 piles of cards with the first pile having 1 card, second having 2 cards, etc. up to the seventh pile having 7 cards
- Only the top card of each pile is face up
- The remaining cards form the stock (draw pile)
- There are 4 foundation piles (one for each suit)

## Gameplay
- Cards can be moved from the tableau (7 piles) to foundation piles if they build up from Ace to King in suit
- Face-up cards in the tableau can be moved to foundation
- A card from the stock can be drawn to the waste pile (face up)
- Cards in the tableau can be moved to build down in suit
- Cards in tableau can be moved to build down in alternating colors (red on black, black on red) 
- Empty tableau spaces can be filled with Kings or any face-up card that can be moved to a foundation pile

## Winning
The game is won when all 52 cards are moved to the four foundation piles.

## Scoring
- Each card moved to foundation: +10 points
- Each card moved from stock to waste: +1 point
- Each empty tableau space filled with a King: +10 points
- Each undo: -1 point
- Each hint: -1 point
